<a id="overview"></a>

**BattleForge** is a completely free online real-time strategy game for Windows that combines elements of classic RTS games like Starcraft with collectible card game mechanics reminiscent of Magic. Set in a vibrant fantasy universe, **BattleForge** allows players to engage in both cooperative and player versus player battles using a unique system of collectible cards to summon creatures and cast spells.
